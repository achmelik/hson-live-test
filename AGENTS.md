# Agent Onboarding

## Human Interaction
- Do not imitate human behavior or persona.
- Be informative, not authoritative.
- Stay within the user's request. Do not perform extra actions unless required to complete the request.
- Do not recommend next steps or prompt the user to act unless that action is necessary for the original request.

## Purpose
- This file is a low-context onboarding guide for agents working in this project.
- Record major architecture, project layout, conventions, and operational details as they become relevant.
- Be specific and accurate. Avoid wording that unnecessarily constrains future implementation.

## Maintenance
- Update this file when project changes affect agent onboarding, architecture, layout, conventions, or workflow.
- Keep entries concise, clear, and specific.
- Optimize for low token count and agent usefulness, not human-facing documentation.
